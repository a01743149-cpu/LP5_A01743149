# HAIL MARY — Landing page

Sitio estático en español, adaptable a celular y computadora. Funciona sin internet: el logo, estilos e interacciones están incluidos en `index.html`.

## Abrir y presentar
1. Abre `index.html` con Chrome, Edge, Safari o Firefox.
2. Pulsa **Presentar**. Avanza con las flechas del control o con las teclas izquierda/derecha. Escape sale del modo de presentación.
3. Para pantalla completa utiliza la opción de pantalla completa de tu navegador.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub (público si utilizas GitHub Free).
2. En **Add file → Upload files**, sube `index.html`, `.nojekyll` y este `README.md` a la raíz del repositorio. No subas únicamente el ZIP ni dejes index.html dentro de una subcarpeta.
3. Guarda con **Commit changes**.
4. Abre **Settings → Pages → Build and deployment**.
5. En **Source**, selecciona **Deploy from a branch**. Selecciona tu rama principal, normalmente **main**, y carpeta **/(root)**. Pulsa **Save**.
6. Cuando finalice la publicación, GitHub mostrará la dirección en esa misma pantalla. Normalmente será `https://USUARIO.github.io/REPOSITORIO/`.

No requiere npm, instalación ni compilación. No contiene formularios que simulen enviar mensajes, rastreadores ni servicios externos.

## Completar antes de la exposición
La empresa desarrolla cohetes, según el encargo. La narrativa, el eslogan y la ruta de ingeniería son propuestas editoriales. No se han inventado mediciones, pruebas ni logros.
Busca en index.html “Por definir”, “Por documentar”, “Por confirmar” y “PENDIENTE DE INCORPORAR” para completar:
- Nombre, dimensiones, masa, materiales y sistema de propulsión del cohete.
- Estado del proyecto, bitácora, fotografías, pruebas y resultados.
- Integrantes, roles y contribuciones.

El dibujo técnico es conceptual, no un plano del prototipo. Sustitúyelo si cuentas con un esquema real.

## Identidad visual
Negro #0B0B0B, azul eléctrico #0066FF y blanco. Se utiliza el logo proporcionado. La familia Bahnschrift se muestra cuando está instalada; de lo contrario se usa Arial. El diseño responde a preferencias de movimiento reducido y permite navegación por teclado.

## Estructura
- `index.html`: página completa y autosuficiente.
- `.nojekyll`: sirve los archivos estáticos sin Jekyll.
- `README.md`: instrucciones de uso y publicación.

No se ha publicado automáticamente en una cuenta de GitHub.
